# GymFlow Member PWA — Feature Specifications

**Version:** 1.1

---

## 1. Authentication

### 1.1 Email + Password Login

**Flow:**
1. Member enters email → system checks if account exists.
2. If new: system sends a secure password setup link (no registration form).
3. If existing: enter password → validate → receive JWT.
4. On success: store session → redirect to Home.

**Edge cases:**
- Wrong password: show "Incorrect password" after 1st attempt; lock for 15 min after 5 failures.
- Unverified email: show "Please verify your email" with resend option.
- Deleted account: show "Account not found. Contact your gym."

### 1.2 Session Management

- Auto-refresh JWT silently in background before expiry.
- If refresh fails (revoked/expired): clear local session → redirect to login.
- Multi-device: login on new device does NOT log out other devices.
- Manual logout: clear all local storage, IndexedDB cache, service worker cache.

## 2. Home Dashboard

### 2.1 Welcome Banner
- "Good Morning/Afternoon/Evening, [First Name]"
- Shows gym logo top-right.
- Background uses gym brand gradient (`--color-brand` to `--color-brand-2`).

### 2.2 Membership Status Card
- Plan name, expiry date, days remaining.

### 2.3 Today's Workout Preview
- Shows day name and first 3 exercises.
- "Start Workout" button.

### 2.4 Attendance Summary
- Current streak (flame icon + number).
- Attendance this month (e.g., "18 / 26 days").
- Tap → navigate to Attendance screen.

### 2.5 XP Progress Widget
- Current level badge.
- XP bar showing progress to next level.
- Tap → navigate to Rewards screen.

### 2.6 Motivation Quote
- Rotates daily from a curated list of 100+ gym/fitness quotes.
- Seed from `day_of_year % quotes.length`.

### 2.7 Recent Notifications
- Latest 3 unread notifications.
- "See all" link → navigate to Notifications screen.

### 2.8 Gym Announcements
- Latest active announcement displayed as a banner.
- Dismissible (dismissed state stored in localStorage keyed by announcement ID).

## 3. Digital Membership Card

### 3.1 Display
- Full portrait card layout using `card-brand` variant (gradient background).
- Gym logo top-centre.
- Member photo (circle, 80px). Falls back to initials avatar if no photo.
- Member name (H2).
- Member code (monospace font `--font-mono`, e.g. "GF-00142") from `members.member_code`.
- Plan name + expiry date.
- QR code (256×256px minimum).

### 3.2 QR Code
- Payload: signed JWT containing `{ member_id, gym_id, exp: now+5min }`.
- Generated by the `generate-qr` Edge Function, not client-side.
- New QR fetched every 4 minutes (auto-refresh timer).
- QR shown even offline (last valid QR payload cached in Dexie.js `metadata` table).

### 3.3 Validation (Owner App side)
- Gym owner scans QR via the GymFlow owner app (`app.gymflow.sbs`) → `validate-qr` Edge Function validates JWT signature → records attendance (source: 'qr').
- If expired QR: show "QR expired — ask member to refresh."
- Attendance insert is idempotent: duplicate scan on same day for same session_type is a no-op.

### 3.4 Screen Brightness
- On mount: request Screen Wake Lock (`navigator.wakeLock.request('screen')`) + request brightness max where API permits.
- On unmount: release wake lock.
- Reacquire wake lock on `visibilitychange` to `visible` (iOS Safari releases on tab switch).

## 4. Attendance

### 4.1 Calendar View
- Monthly calendar grid.
- Present days: filled circle in `--color-brand`.
- Absent days: empty circle (`--border-default`).
- Today: outlined circle with `--border-focus` ring.
- Tap a day → bottom sheet showing check-in time and source (if available).
- Navigation arrows for previous/next month.

### 4.2 Summary Stats
- Current streak (from `get_attendance_streak()` RPC — always live).
- Longest streak (from `member_xp.longest_streak`).
- Total visits all time.
- This month: present days / working days.
- Attendance percentage this month.

### 4.3 Weekly View
- Bar chart (Mon–Sun) for current week using `--chart-attendance` colour.
- Comparison bar: last week (`--chart-attendance` at 30% opacity).

### 4.4 Streak Rules
- Streak increments if member attended on the previous calendar day.
- Streak breaks if a day is missed (no grace day in v1).
- Longest streak stored in `member_xp.longest_streak` — never decrements.

**Edge cases:**
- Same-day duplicate punch (biometric or QR): idempotent — only one attendance record per `(member_id, date, session_type)`.
- Backdated attendance added by gym owner: `get_attendance_streak()` recalculates correctly from DB.

## 5. Membership Screen

### 5.1 Display
- Plan name, joining date (`memberships.start_date`), expiry date, remaining days.

## 7. Workout Module

### 7.1 Plan Overview
- Plan name + goal.
- List of workout days (Day 1 through Day N) with day names.
- Current day highlighted based on `day_of_week % plan.day_count`.

### 7.2 Day View
- Day name + exercise list.
- Each exercise card: name, sets × reps, weight, rest time, expandable notes.

### 7.3 Active Workout Session

**Start:**
- Tap "Start Workout" → POST to `workout_sessions` (creates record with `started_at`).
- Show first exercise.

**Per Exercise:**
- Exercise name + instructions.
- Set rows: set number, target reps, target weight, done checkbox.
- Tap checkbox to complete set → start rest countdown.
- Rest countdown: full-screen countdown with `--font-mono` timer display, skip button.
- Haptic feedback on set completion: `navigator.vibrate?.([15])`.

**Navigation:**
- Swipe left/right or tap "Next / Previous Exercise".
- Progress indicator: "Exercise 3 / 8".

**End:**
- Tap "Finish Workout".
- Confirmation dialog (elevation 4): "Are you sure? You've completed 6/8 exercises."
- On confirm: PATCH `workout_sessions` with `completed_at`, `duration_min`, `exercises_done`, `sets_done`, `volume_kg`. Award XP. Show summary.

**Summary screen:**
- Duration, exercises done, sets completed, estimated volume (kg).
- XP earned (animated `+N XP` float using `--color-xp-text`).
- "Back to home" button.

**Edge cases:**
- App goes background mid-workout → session stays open (Screen Wake Lock released; session record stays `completed_at = NULL`).
- Offline mid-workout → set completions write to Dexie.js sync queue; sync on reconnect.
- Force-quit → on next open, detect `workout_sessions` row with `started_at` set but `completed_at = NULL` for today → offer "Resume" or "Discard."

### 7.4 Workout History
- List of completed sessions, newest first.
- Each: date, duration, exercises done, XP earned.
- Tap → bottom sheet with set-by-set detail.

## 8. Diet Plans Screen

## 9. Progress Tracking

### 9.1 Log Measurement
- Form: weight (kg), body fat (%), chest (cm), waist (cm), hips (cm), arms (cm), shoulders (cm), thighs (cm). All optional except date.
- Tap "Save" → POST to `progress_measurements`. Award 30 XP (once per week max, enforced server-side in Edge Function).

### 9.2 Charts
- Weight chart: line chart (30d default) using `--chart-weight` colour.
- Body composition charts: line per measurement type.
- Tabs or horizontal scroll for different measurement types.
- Time range toggle: 7d / 30d / 90d / All.
- Empty state: illustration + "Log your first measurement" CTA.

### 9.3 Progress Photos
- Upload: tap + → native file picker (camera or gallery).
- Types: Before / Progress / After (shown as chip selector).
- Stored in Supabase Storage under `member-photos/{member_id}/` with RLS.
- Gallery: chronological grid, newest first.
- Tap photo → full-screen lightbox with date label.

## 10. Notifications

### 10.1 In-App Notification Centre
- Bell icon in top-right of Home with unread count badge (red dot, `--color-error`).
- List: newest first.
- Each row: icon by type, title, body preview, relative timestamp, unread dot indicator.
- Tap row → mark `is_read = true` + navigate to `data.link` deep link.
- "Mark all read" button patches all unread rows.

### 10.2 Push Notifications
- On first login: friendly explanation screen → prompt for push permission.
- On grant: subscribe via Web Push API → POST subscription to `register-push` Edge Function → saved to `push_subscriptions`.
- On denial: do not prompt again. Opt-in available from Profile > Settings.

### 10.3 Notification Types and Deep Links

| Type | Trigger | Deep Link |
|---|---|---|
| Membership expiring | 14 / 7 / 3 / 1 day before `end_date` | /membership |
| Payment due | When pending payment created | /payments |
| Workout assigned | New plan linked to member | /workout |
| Diet plan updated | Plan modified | /diet |
| Gym announcement | Admin publishes announcement | /home |
| Challenge started | Challenge `starts_at` date | /rewards/challenges |
| Badge earned | Badge trigger fires | /rewards/badges |
| XP milestone / level up | `member_xp.level` increments | /rewards |
| System | Gym owner message | /notifications |

## 11. Profile

### 11.1 Personal Details
- Name, email, phone, date of birth, gender, blood group.
- Tap any field → inline edit → tap save icon.
- Photo: tap avatar → bottom sheet → choose camera or gallery → upload to `member-photos/{member_id}/avatar.webp`.

### 11.2 Emergency Contact
- Name and phone.
- Stored in `members.emergency_name` and `members.emergency_phone`.
- Displayed to gym owner/trainer when viewing member profile in the owner app.

### 11.3 Medical Notes
- Free text input.
- Stored in `members.medical_notes`.
- Visible to trainer when viewing member profile in the owner app.

### 11.4 Settings
- Push notification preferences: toggle per notification type (maps to a JSONB preferences field; future table migration in v1.1).
- Biometric login (future).
- Language preference (future).

### 11.5 Privacy
- "Download my data" — exports member's own data as JSON (profile, attendance, workouts, payments).
- "Delete account" — sends deletion request to gym owner via in-app notification; cannot self-delete in v1.

### 11.6 Logout
- Confirmation dialog.
- Calls `POST /auth/v1/logout`.
- Clear all Dexie.js tables, TanStack Query cache, and service worker runtime cache.
- Redirect to login.

## 12. Referral Program

### 12.1 My Referral Code
- Unique code displayed (e.g. "GF-GANE42"), generated from `referrals.referral_code`.
- Share button: copies referral link to clipboard or opens native Web Share API.
- Link format: `https://member.gymflow.sbs/join?ref=GF-GANE42`

### 12.2 Referral Status
- List of referrals: partial name (for privacy), status badge (pending / joined / rewarded), date.
- Summary: "Invited X friends, Y joined."

### 12.3 Referral Joining
- New member opens referral link → pre-fills referral code in registration flow.
- On first payment confirmed: both referrer and referred receive 200 XP (via `award_xp` Edge Function).
- `referrals.status` updated to `rewarded`; `rewarded_at` stamped.

## 13. AI Coach (Premium — v2 only)

> **Not in v1 scope.** Planned for v2. See Development Roadmap §5.

### 13.1 Chat Interface
- Standard chat UI (message bubble layout).
- System prompt includes: member's current workout plan name + exercises, latest 3 measurements, membership goal, gym name, first name.
- Member can ask: workout advice, nutrition questions, exercise form tips, motivation.

### 13.2 Access Control
- Feature flag per gym (`gyms.ai_coach_enabled` — v2 schema addition).
- If not enabled: locked screen with "Ask your gym to enable AI Coach."

### 13.3 Data Passed to AI
- Current workout plan name + exercises.
- Latest 3 measurements.
- Membership goal.
- No PII beyond first name. No payment data, no medical notes.
